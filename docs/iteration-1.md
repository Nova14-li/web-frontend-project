1. **问题**：如何实现共用功能的代码复用而不是几个难点分别写代码？
2. **排查过程**：把三个难点的画面摊开对比，发现真正相同的只有三样：取数据、代码区渲染 + 行高亮、播放控件那五个动作；d1 的栈帧与图例、d2 的判定区与槽位、d3 的滑块与曲线差异很大。于是只抽这三样，其余坚决不抽。
3. **解决方案**：`common.js` 里给工厂函数，页面通过参数把自己的"画面怎么画"传进去（`onStep` 回调）。播放器只知道"第几步"和一个定时器，完全不知道栈帧长什么样；代码面板只切 `.active`，行内怎么标由页面自己决定。

1. **问题**：单步前进好做，点一下重画就行；但"单步回退"一开始完全做不出来——弹掉的帧已经从页面上删了，回退时没有数据可以还原。第一版是"回退 = 把 n 重新算到第 k 步"，每点一次整个递归重跑一遍，n 到 8 以上就卡，而且和正向点过来的状态对不上。
2. **排查过程**：把两件事分开记——①当前要显示什么（画面）②递归算到了哪一步（计算）。发现自己把两者混在一个函数里：`fib(k)` 里边算边改 DOM，于是回退只能靠"重算"。再回看开题说明里难点 1 那句"每调用一次就真的新增一张独立卡片"，意识到卡片必须有**历史**，不能是"当前状态"的唯一副本。
3. **解决方案**：计算与渲染拆开。计算阶段用真递归跑一遍，每发生一件事（入栈、判基线、转等待、返回、求和）就把当时的栈**拷贝**一份存档；渲染只管"把第 i 份快照画出来"，所以第 i 步不依赖第 i-1 步做过什么，回退就是 `goTo(i - 1)`。
4. **如何验证已解决**：n=3 生成 17 步，从第 17 步连点"单步回退"到第 1 步，帧数、帧上的 state、解说文字与正向点过来完全一致（对着纸上的手算结果逐帧核过）；n=10（619 步）时回退到中间某步不卡，也没有"重算一遍"的延迟。

发现并修掉的问题（3 个，都在 8c2fc27 合并进仓库之前就改掉了，仓库里能查到的已是改后版本）：①快照没拷贝——`stack: stack` 让 17 个步骤共用同一个数组，回退后帧数不变，因为所有步骤画的都是"最后一次的栈"，这是在测"回退到第 1 步应该只剩 1 张卡"时发现的，改成 `stack.map((f) => ({ ...f }))`；②`0` 被当成空值——`fill` 第一版是 `vars[key] || m`，`fib(0)` 那步返回 0，解说条上直接显示 `{value}`，这个 bug 只在 n≥2 的基线分支出现，不看 n=3 的完整流程根本发现不了，改成 `??`；③文案硬编码在 JS 里——AI 给的版本把中文写在 `snap('test', ...)` 的模板字符串里，与"数据与页面分离"直接冲突，也不方便改词，全部搬到 `d1.json` 的 `steps` + `frame` 两段，JS 里只留 `id`。

### 4.4 本迭代 AI 使用反思

- AI 帮助最大的环节：把"我想要的效果"翻译成"代码结构"。我最卡的两个点——"每一步怎么留住"和"五个按钮怎么共用一个定时器"——自己闷头想了两天没结果，AI 分别给了"快照数组"和"闭包 + 一个 index + 一个 timer"两个方向，路就通了；
- 踩过的坑（如：生成的代码用了课内未讲的特性、命名风格与项目不一致）：语法超纲是最主要的一条，AI 大量用 `?.`、`??`、`...f`、`Array.from`、`replaceChildren`、`dataset`，课上都还没讲，第一遍基本是照抄，后来要求自己"每个符号都能用自己的话解释"才敢合并；命名风格也不一致，AI 爱用 `out`、`snap`、`tpl`、`emit` 这种两三个字母的名字，我习惯 `stackList`、`narrationText`，最后统一成"短名只在函数内部用，跨函数写全"；AI 不知道我的项目上下文，一开始给的类名是 `.stack-frame`，而我 CSS 里写的是 `.frame`，样式全不生效，白找了一刻钟；错误处理基本不写，数据 404、n 非法、按钮越界都是我自己补的。最该记住的是"看起来对"最危险：`stack: stack` 语法完全正确、逻辑看着也顺，只有真去回退才暴露。
- 下一迭代的调整策略：①提示词固定加三句约束——"只用我学过的语法，超纲的请单独说明""中文文案一律从 JSON 读，不要写死在 JS""类名沿用 style.css / d1.css 里已有的"；②先自己写一版能跑的（哪怕很丑），再让 AI 只改一个具体函数，这样对比才成立也不至于看不懂；③每次合并只提交一个功能点，commit message 写清"AI 生成 / 我改了哪里"，方便出问题回滚；④把这次的边界值清单（最小、最大、非法、越界、刷新、窄屏）固化下来，每接一个新函数就照着过一遍。
